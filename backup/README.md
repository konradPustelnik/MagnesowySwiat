# Poprzednia wersja Magnesowego Świata

Otwórz `index.html` w tym folderze albo adres `/backup/` na stronie. Zachowano oryginalne HTML, logo i zasoby bez zmian, łącznie z dotychczasowymi ograniczeniami formularzy. `manifest-sha256.json` zawiera sumy kontrolne oryginalnych plików.

Nowa strona główna znajduje się jeden katalog wyżej. Backup nie jest umieszczony w sitemap; robots.txt wyklucza ten folder z indeksowania. Oryginalne adresy canonical w kopii wskazują domenę główną.

Aby przywrócić stary wygląd, skopiuj `index.html`, katalogi `assets/`, `magnesy-na-zywo/`, `magnesy-na-zamowienie/` i oba pliki logo z tego folderu do głównego katalogu projektu. Przy przywracaniu trzeba także przywrócić sitemap i robots oraz usunąć nowe podstrony `.html` z nawigacji, jeśli przestaną być używane. Nie usuwaj backupu przed sprawdzeniem przywróconej wersji.
